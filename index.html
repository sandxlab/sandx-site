Design Philosophy

Infrastructure, not a product.

SandX is a computational layer that other systems build on. Every engine is independently deployable and composable. Outputs carry probabilistic confidence scores, not binary decisions. All benchmarks are versioned and re-runnable.

Technical credibility is the foundation. Built to earn trust by working — rigorous, reproducible, and production-grade.

  • — Composable by design: use one engine or all four
  • — Probabilistic-first: every output has a confidence score
  • — Reproducible: all benchmarks re-runnable from public data
  • — Python-first API with R and TypeScript SDKs following
quickstart.py 
from sandx_er import EntityResolver

# configure a blocking + matching pipeline
er = EntityResolver(
    blocking="lsh",
    similarity="embedding",
    threshold=0.85
)

# resolve a noisy record set
result = er.resolve(records)

# structured output with confidence
for cluster in result.clusters:
    print(cluster.canonical_id,
          cluster.size,
          cluster.confidence)
Platform API

Use it over HTTP.

The SandX Platform API wraps all four engines as a managed REST service. Send records, get resolved clusters back — no Python environment required.

Authenticate with an API key. Self-host in one command via Docker, or use the managed endpoint.

  • — POST /v1/er/resolve — entity resolution
  • — POST /v1/graph/consensus — graph reasoning
  • — POST /v1/embed/encode — embeddings
  • — POST /v1/compute/jobs — distributed compute
Self-host on GitHub 
# resolve entity identity across records
curl -X POST localhost:8000/v1/er/resolve \
  -H "Content-Type: application/json" \
  -d '{
    "records": [
      {"id":"1","name":"Acme Corp", "city":"Boston"},
      {"id":"2","name":"Acme Corp.","city":"Boston"}
    ],
    "config": {"threshold": 0.4}
  }'

# response
{
  "clusters": [{
    "canonical_id": "3f2a1b8c-...",
    "record_ids":  ["1", "2"],
    "confidence":  0.81,
    "size":        2
  }],
  "n_records": 2,  "n_clusters": 1,
  "elapsed_ms": 4.2
}
import requests

resp = requests.post(
    "http://localhost:8000/v1/er/resolve",
    headers={"X-API-Key": "sk-dev"},
    json={
        "records": [
            {"id": "1", "name": "Acme Corp",  "city": "Boston"},
            {"id": "2", "name": "Acme Corp.", "city": "Boston"},
        ],
        "config": {"threshold": 0.4}
    }
)

for c in resp.json()["clusters"]:
    print(c["canonical_id"][:8],
          c["size"], c["confidence"])
# 3f2a1b8c  2  0.81
